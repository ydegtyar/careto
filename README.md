## About

Careta is a modern web application for managing car expenses, tracking mileage, and organizing vehicle‑related data. It provides a clean UI for logging fuel, maintenance, and other costs, while offering analytics dashboards to visualize spending trends. Designed for both individual drivers and small fleets, it helps users stay on top of budgeting, reminders, and vehicle health.

## Features

- **Expense Tracking**: Log fuel, maintenance, insurance, and other vehicle costs.
- **Receipt Capture**: Upload and compress receipts with automatic image handling.
- **Mileage & Entry Math**: Automatic calculation of mileage and expense totals.
- **Analytics Dashboards**: Visualize spending trends with Recharts donut and bar charts.
- **Vehicle Management**: Manage multiple vehicles, view details, and switch between them.
- **Reminders & Notifications**: Set service and maintenance reminders.
- **Sync & Offline Support**: Real‑time sync via Neon, SQLite‑WASM, and PWA offline caching.
- **Authentication**: Email/password and magic‑link login via Better‑Auth.
- **Responsive UI**: Built with Material‑UI (MUI) v9, custom theme, and TanStack router.
- **Developer Tools**: Auto‑update PWA hook, broadcast channel for DB changes, and environment‑specific configurations.
